Threat Intelligence Automation System

How the whole thing works — the weekly pipeline, the moving parts, and who actually writes the summaries.

In one sentence: Every week it auto-scrapes cyber-threat news → a local AI model summarizes it → a human manager approves by email → the format is validated → a clean SOC report is auto-emailed to the team — with a live dashboard watching the whole thing.

① The weekly pipeline

The journey of one threat report, start to finish. Blue = automatic · Amber = a human decides · Green = goes out.

1

Scrape the news automatic Mon 10:00 AM IST

Pulls articles from 6 cyber-news feeds (Hacker News, Krebs, Bleeping Computer, Bank Info Security…), scores each for financial-sector relevance (SEBI, RBI, UPI, CVE, zero-day…) and saves them.  web_scraper.py → database.py

2

Summarize & build report automatic local AI

A local BART model writes the “Threat Summary” & “Description”; the report is formatted into HTML/Excel.  soc_report_formatter_enhanced.py

3

Manager review human gate

The top articles are emailed to a manager with Approve / Reject buttons. A click hits the callback server, which records the decision.  email_system.py → callback_server.py

4

Sender validation human gate

A second check confirms the report is correctly formatted (another approve/reject email) before it can leave.  sender_validation.py

5

Deliver to SOC sent target: Tue 11:00 AM

Once validated, the final HTML report is emailed to the SOC team; the scheduler manages the timing.  scheduler.py → email_system.py

③ Who writes the summaries?

A local, free, open-source model on your own machine — no Gemini, no OpenAI, no cloud API.

soc_report_formatter_enhanced.py → create_clear_summary()

Cleaned article text goes in. The code tries the AI model first, and falls back if it isn't available:

🧠 Path A — AI (preferred)

BART facebook/bart-large-cnn condenses the real article into a summary. Relevant sentences are picked first using all-MiniLM-L6-v2 + scikit-learn. Runs locally (~1.5 GB, cached after first download).

📝 Path B — Rule-based fallback

If the AI libraries aren't installed/loadable, it just extracts the best 2–5 real sentences with regex/heuristics. No AI involved.
